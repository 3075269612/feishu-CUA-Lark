# 基础操作能力说明

课题要求 CUA Agent 支持飞书桌面客户端的基础 GUI 操作。CUA-Lark 当前以真实稳定链路需要的操作为优先，Backend 层保留扩展空间。

## 当前已用于主链路的能力

| 能力 | 当前状态 | 用途 |
| --- | --- | --- |
| 单击 | 已实现并真实使用 | 点击消息入口、群聊、云文档、新建、文档类型、标题区域等。 |
| 文本输入 | 已实现并真实使用 | 通过剪贴板粘贴中文/英文/数字/run_id，规避输入法不稳定。 |
| 快捷键组合 | 已实现并使用 | 搜索、粘贴、页面操作、部分状态机导航。 |
| Enter / 按键 | 已实现并真实使用 | IM 发送、搜索确认、键盘驱动流程。 |
| 截图 | 已实现并真实使用 | 每步 observation、验证、报告和 Phase 8 数据导出。 |
| 窗口聚焦 | 已实现并真实使用 | 执行前聚焦飞书窗口。 |

## Backend 层可扩展能力

| 能力 | 当前策略 |
| --- | --- |
| 双击 | 可通过两次 click 或后续 backend `double_click` 包装实现；当前真实稳定链路未依赖。 |
| 右键 | 可在 backend 层扩展；当前安全策略不鼓励在真实飞书中使用右键菜单完成核心任务。 |
| 拖拽 | 可在 backend 层扩展；当前 IM / Docs smoke 不需要拖拽，Calendar/Base 复杂场景后置。 |
| 滚动 | 可在 backend 层扩展；当前通过搜索、OCR、菜单状态机减少滚动依赖。 |

## 工程取舍

- 中文输入优先使用剪贴板粘贴，不逐字模拟输入法。
- 真实 UI 主链路禁止无证据固定坐标 fallback；定位失败应 `blocked` 并写入 trace。
- API 不执行 GUI 任务，只做 Oracle 验证。
- 后续如果扩展 Base、长文档编辑或复杂日历选择器，应优先补滚动、拖拽和右键的 backend 封装及 mock/单测。
